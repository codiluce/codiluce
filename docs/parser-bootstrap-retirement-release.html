Completed change

Source-free template compiler prewarming now uses the same retirement barrier as queued source jobs. It cannot start a replacement during explicit shutdown or deadline recovery. Fresh prewarming resumes after the old process exits, without dispatching source or importing the optional compiler.

The prior implementation fails the explicit shutdown regression. Both new retirement cases pass, with no overlapping worker address spaces observed. All 26 targeted cases, all 1,703 engine/web tests, both typechecks, deterministic documentation, the CLI build and 19 ordinary compiled Node checks pass without skips.
