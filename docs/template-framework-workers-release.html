Completed change

The optional Svelte compiler and Astro Rust native parser load only inside a source parser worker. Each generation retires after 64 original jobs or 16 MiB of cumulative UTF-8 inputs. An individually allowed larger original parses alone and immediately retires. Replacement waits for actual process exit; indexing completion, failures, deadlines and explicit closure also await retirement.

The complete enumerable AST data and native error messages/positions cross the worker boundary. Tests compare shared references, BigInt/RegExp values and Unicode/CRLF locations. Target sources, imports and configuration never execute. A separate owning process cannot resolve either optional parser and still completes original-source indexing.

Generation accounting and the worker's 256 MiB V8 old-space ceiling are separate from native allocation, parent AST/checker ownership and physical RSS.
