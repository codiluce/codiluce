# Design documents

- [Software design and architecture feasibility](software-design-architecture-feasibility.html): research on
  visualizing SOLID, ports and adapters, dependency injection, all 23 GoF patterns, and advanced architecture
  techniques; deterministic checks, optional LLM assistance, current analyzer gaps, and a staged proposal.
  Open the self-contained HTML in a browser. Research only; no application implementation.
- [Agent harness compatibility roadmap](agent-harness-compatibility.html): ten target harnesses, MCP, hooks,
  session history, subagents and characters, with an extensible adapter design and delivery plan. Open the
  self-contained HTML in a browser.
- [Harness connection guide](../agents/harnesses.md): implementation, twelve adapters, runtime profiles,
  configuration, history imports and validation coverage.
- [Agents: observed activity on the map](agents.md): current Codex and Claude Code activity and session behavior.

## UI concept, 2026-10-07

An early, illustrative mockup of the visualizer, made before the brand was chosen. It
introduced the Dawn and Dusk themes and the amber "illumination" accent. It shows an
example app, not real data, and nothing in the build reads these files.

- `ui-concept-standalone.html` opens directly in a browser.
- `ui-concept.html` is the same concept as an embeddable fragment.

The current identity is in [../brand/README.md](../brand/README.md).
