# UI concept, 2026-10-07

An early, illustrative mockup of the visualizer, made before the brand was chosen. It
introduced the Dawn and Dusk themes and the amber "illumination" accent. It shows an
example app, not real data, and nothing in the build reads these files.

- `ui-concept-standalone.html` opens directly in a browser.
- `ui-concept.html` is the same concept as an embeddable fragment.

The current identity is in [../brand/README.md](../brand/README.md).
