Recorded target inputs qualify source contracts on Linux; they do not establish native Windows/macOS execution or framework runtime validity. Target dependencies, toolchains, applications, plugins and hooks never run. The literal fixtures are authored qualification inputs, not upstream repository accuracy evidence.

Cold scans have no cache. Population, warm and a shared Node dependency edit are timed separately. Both original consumer call targets bind to the shared source; the edit invalidates their connected cache unit while unrelated TypeScript units stay hits. Warm graph, syntax and semantic cache events are recorded by analyzer; a qualified PHP graph hit skips native-tree hydration. The cache keeps at most two versions per unit, 256 MiB compressed overall and 64 MiB decoded per entry; oversized/corrupt entries fall back to source rather than blocking indexing.

The 4-commit history edits the shared dependency and an original PHP body, then renames a Vue component; deeper revisions also edit and repeatedly rename an original Python file. Two history workers materialize original Git trees; snapshots include complete entities, relations and diagnostics, not just counts. Only working-tree Git metrics and Git-availability diagnostics are normalized for live-versus-revision comparisons. All semantic metadata, evidence and original ranges remain in the digest.

A separate process polls every thread's descendant list every 25 ms, with an acknowledged start marker before synchronous work. RSS sums include history and parser children; shared pages can be counted repeatedly, exiting processes can make a poll incomplete, and peaks between polls can be missed. Raw parent VmHWM is cumulative since exec, not an isolated warm/history peak. Source memos are limited to 32 MiB of conservative UTF-16 text/key payload and 4,096 entries per instance; compiler/semantic consumers can retain their own text and ASTs, so this is not an RSS cap. Each historical worker now waits until the parent stores or records failure for its one graph before analyzing another commit. The ordinary sample remains below the byte limit; a separate source-pressure profile exercises eviction. Per-commit RSS checkpoints are observations after result delivery, not instantaneous or independent peaks. Native OS readers, wider WASM/AST budgets, much longer histories and production-repository accuracy remain additional P10d gates. This report records its named phase against the archived baseline.
