Choose a fresh output directory for every observation. The runner refuses an existing directory and any output inside a target repository, including paths through symlinks. Open its index.html in a browser; receipt.json retains each outcome, complete corpus identity and before/after verifier checksums, and corpus.json retains all original pins. --corpus FILE selects an explicitly reviewed alternative corpus. It never clones or refreshes revisions automatically.

Every revision pins its complete commit, root tree, original parents and SHA-256 of the exact NUL-delimited Git tree inventory. That inventory identifies paths, file modes and Git object IDs. Regular files, symlinks and gitlinks are counted separately. The verifier disables Git replacement objects, inherited Git overrides, global/system configuration and filesystem monitoring; it never runs hooks, filters, submodules, LFS, target code, dependencies or builds. A dirty or differently checked-out working tree cannot substitute for pinned Git objects. The actual checked-out head is recorded separately.

The inventory hash is metadata evidence. Original blob-byte SHA-256 validation, materialization and analysis are follow-on requirements.
